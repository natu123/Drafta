---
description: Changesを内容別にカテゴライズしてcommitし、pushするワークフロー
---

1. **変更の確認**:
   - `git status` と `git diff` を使用して、現在変更されているファイルと内容を確認します。

2. **論理的なグループ分け**:
   - 変更内容を「機能追加 (Feat)」「修正 (Fix)」「リファクタリング (Refactor)」「ドキュメント (Docs)」「設定 (Chore)」などの論理的な単位にグループ分けします。

3. **コミットの実行**:
   - 各グループごとに `git add <files>` と `git commit -m "<Type>: <Description>"` を繰り返します。
   - コミットメッセージは日本語で、簡潔かつ具体的に記述します。

4. **プッシュ**:
   - 全ての変更がコミットされたら、`git push` を実行してリモートリポジトリに反映します。
