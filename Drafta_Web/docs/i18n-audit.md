# 多言語対応監査

監査日: 2026-08-07

## 対象

- 対象ファイル: `src/lib/translations.ts`
- 対応言語: 英語、日本語、中国語 (簡体字)、韓国語、ヒンディー語、アラビア語、ロシア語、インドネシア語、スペイン語、フランス語、ポルトガル語 (ブラジル) の11言語
- 対象画面: ランディングページとアプリ

## 現状

`translations.ts` は、言語メタデータ、アプリ用の `AppT`、ランディングページ用の `T`、両画面の翻訳データを1ファイルで管理しています。翻訳キーの型は定義されていますが、言語選択の状態とドキュメント属性は画面間で共有されていません。

## 設計上の改善点

1. ランディングページとアプリが、それぞれ `en` を初期値とする独立した言語状態を持っています。画面遷移時に選択言語が引き継がれません。
2. 選択言語を保存していないため、再読み込み時に英語へ戻ります。
3. ルートレイアウトの `<html lang="en">` が固定されており、表示言語を変更しても支援技術や検索エンジンへ反映されません。
4. アラビア語を選択しても `dir="rtl"` が設定されません。
5. 言語メタデータと2画面分の翻訳が単一ファイルに集中しており、差分確認と翻訳レビューの範囲が広くなっています。
6. 翻訳キーの一致は TypeScript の型で確認できますが、意図的な英語表記と未翻訳文字列を区別する仕組みがありません。

## 翻訳内容の確認事項

英語版と完全一致する値を機械的に比較しました。一致していても、製品用語や借用語として正しい場合があるため、未翻訳と断定せず確認事項として扱います。

### ランディングページ

| 言語 | 英語版と同一のフィールド |
| --- | --- |
| 日本語 | `subTagline`, `beforeTitle`, `ctaButton`, `featuresTitle`, `platformTitle`, `platformBeta`, `platformComing` |
| 中国語 (簡体字) | `subTagline`, `platformBeta` |
| 韓国語 | `subTagline` |
| ヒンディー語 | `subTagline` |
| アラビア語 | `subTagline` |
| ロシア語 | `subTagline` |
| インドネシア語 | `subTagline`, `platformBeta` |
| スペイン語 | `subTagline`, `platformBeta` |
| フランス語 | `subTagline`, `platformBeta` |
| ポルトガル語 (ブラジル) | `subTagline`, `platformBeta` |

`subTagline` は、英語以外の全10言語で英語版と同一です。`platformBeta` の `Beta` は複数言語で一般的に使われる可能性があるため、意図的な共通表記か確認が必要です。

### アプリ

アプリ用の翻訳は、英語版との比較ではほぼ各言語固有です。`sortManual` の `Manual` だけが、インドネシア語、スペイン語、ポルトガル語 (ブラジル) で英語版と同一です。これも正しい共通表記の可能性があるため、翻訳漏れとは断定しません。

### 言語ラベル

インドネシア語の選択肢ラベルは `Indonesia` です。国名ではなく言語名を示す意図であれば、`Bahasa Indonesia` などへの変更をネイティブ話者または翻訳方針と照合する必要があります。

## 推奨する実装単位

1. 言語コード、表示名、書字方向を共有メタデータとして定義します。
2. ルート付近に共通の言語プロバイダーを置き、ランディングページとアプリから同じ状態を参照します。
3. 選択言語を `localStorage` に保存し、Hydration mismatch を起こさない読み込み手順を定義します。
4. 選択言語に合わせて `<html>` の `lang` と `dir` を同期します。
5. 言語メタデータ、ランディングページ翻訳、アプリ翻訳を責務別のモジュールへ分割します。
6. 翻訳キーの一致と、英語のまま残すことを承認したフィールドの Allowlist を自動テストします。

## 完了条件

- ランディングページで選んだ言語が、アプリへ移動しても維持されます。
- 再読み込み後も選択言語が維持されます。
- 英語、日本語、アラビア語で `lang` が正しく更新されます。
- アラビア語で `dir="rtl"`、それ以外で `dir="ltr"` が設定されます。
- 既存の翻訳文は、承認された修正を除いて逐語的に維持されます。
- 全11言語の翻訳キーが一致し、未翻訳候補または意図的な共通表記が明示されます。

## 保留事項

- `subTagline` を含む英語と同一の各フィールドは、承認済み翻訳または翻訳方針が必要です。
- `Beta` と `Manual` を共通表記として残すかは、製品用語の方針確認が必要です。
- インドネシア語の言語ラベルを変更する場合は、採用する表記の確認が必要です。

翻訳文の新規作成は本監査の対象外です。内容を推測で補わず、状態共有と文書属性の改善を先行できる構成とします。
