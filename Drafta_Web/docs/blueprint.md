# **App Name**: Draftio × Prōla

## Core Features:

- Note Creation and Organization: Create notes with text, handwriting, and voice input. Organize notes into groups and bookmark them with 1-3 stars.
- Rich Text Editor: Full Markdown support, with accurate rendering of line breaks and spacing. Support for text colors (#2D7BA1, #DECA28, #AD46FF, #31D492, #51A2FF).
- AI Integration (Prōla): Integrate AI services (Perplexity, ChatGPT, Gemini) directly within Draftio. Implement a unified UI/UX for all features, as a tool
- AI Chat Sessions: Create and manage AI chat sessions like notes, displaying message timestamps and author names. Allow users to edit their sent messages.
- Layout and Customization: Layout with a vertical note list and tab bar on the left, and an AI integration window on the right. Option for smartphone-like thumbnail tab switching.
- Markdown Conversion: Enable two-way conversion between Markdown and plain text.
- Search Functionality: Enable a robust page search to allow for quickly locating of relevant content. Implement standard Redo/Undo features for simple and safe editing.

## Style Guidelines:

- Primary color: #2D7BA1 for a calm and professional feel, reflecting the note-taking and AI integration aspects.
- Background color: Desaturated light yellow (#F8F5EC) to provide a gentle, distraction-free workspace.
- Accent color: #DECA28 for highlights and interactive elements, adding a touch of sophistication.
- Body and headline font: 'PT Sans', a modern humanist sans-serif. Note: currently only Google Fonts are supported.
- Left-side vertical note list and tab bar. Auto-minimizing sidebars for a clean, focused workspace.
- Optional smartphone-style thumbnail tab switching for easy navigation.
- Clean, minimalist icons for note groups, bookmarks, and AI service options.
