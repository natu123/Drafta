# Retrospective（振り返り）

直前に解決した問題やバグについて振り返りを行い、再発防止策を検討してください。

## 出力フォーマット

### 🔍 問題の本質
- 何が起きていたか（症状）
- なぜ起きたか（根本原因）

### 🛡️ 再発防止策
- 同種の問題を防ぐための抽象的な教訓
- コードレビュー時のチェックポイント
- 設計・実装時の注意点

### 📝 CLAUDE.md への追記提案（該当する場合）
- Engineering Protocol や Conventions に追加すべき項目があれば提案
