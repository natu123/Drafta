# PC・タブレットの画面構成 (3列と上部のタブ)

採用日: 2026-10-23. Glesさんの依頼 (「Writing Modeにするとタブ一覧が見られない. デザインとしてはPWA版の方が優れている. スマホ版を参考にWeb版のデザインを刷新して」) に対し, Options Firstで3案 (3列+上部タブ・左端の細いメニュー・今の形でタブを常に出す) を示し, Glesさんが「3列+上部タブ」を選びました. 対象は幅768px以上 (タブレット768〜1279px, PC 1280px以上) です. スマホ (768px未満) は`specs/19_mobile_design.md`のままです.

## 背景

- 画面の上端に, ロゴ・検索・Writing Modeの切り替え・アカウント・最近開いたメモ・言語・設定を並べた共通ヘッダー (57px) がありました. 3列の上にもう1段の見出しが重なり, 縦の領域を使っていました.
- 開いているメモ (タブ) は, Writing Modeに切り替えたときだけ左端の縦の一覧に出ました. 通常の3列では開いているメモの一覧がなく, Writing Modeではトレイとメモの一覧が見えませんでした.
- スマホ版は, アプリ全体の操作をトレイ一覧の見出しに置き, タブは下部ナビから一覧で開けます. PC・タブレットでも同じ考え方に揃えます.

## 構成

```
┌ Drafta  🔍 🌐 ⚙ ☁👤 ┬ 📥 Inbox      ☑ — ┬ ⇤ 🌱 メモA             [⬚2 タブ] 🕘 ┐
├ トレイ            —  │ ☐ メモ             │ 🔍 ↶ ↷ … ☰            📌 🕘 🗑     │
│ 復元                 │ ☐ メモ             │ 🌱 メモA                             │
│ Personal / Work …    │ 📌 ピン留め         │ 本文…                                │
│ (+) トレイを追加     │ (+) メモを追加      │                                      │
└──────────────────────┴─────────────────────┴──────────────────────────────────────┘
```

### 1. 上端の共通ヘッダーをなくす

- 共通ヘッダーは出しません. Playgroundの帯 (保存されない旨) は従来どおり最上部に出します.
- アプリ全体の操作の段 (`.app-bar`, 高さ57px) を, **いちばん左に見えている一覧の列の上端**に置きます. PCはトレイの列, タブレットはメモの列です (タブレットのトレイ一覧は引き出しのため). スマホのトレイ一覧の見出しと同じ考え方です.
- 段の中身は, 左にDraftaのアイコン (Landing-pageへのリンク), 右に検索・言語・設定・アカウント (保存の状態とアカウントのメニュー) です. タブレットでは左端に「トレイを開く」(☰) を置きます.
- PCのトレイの列は, 段の下に従来の見出し (「トレイ」と区切り線の追加) を置きます. 段の操作が収まるよう, トレイの列の幅は最小208pxとします (初期値は画面幅の1.7/12と208pxの大きい方. メモの列は, エディタに720px残るように縮めます).

### 2. ツールバーの行のタブと, 常に見えるタイトル欄

- エディタのツールバーの行の先頭に集中表示の切り替え, 右端 (メモの操作の前) に「タブ」(件数の四角, スマホの下部ナビと同じ) と最近開いたメモ (🕘, 従来の共通ヘッダーの履歴) を置きます.
- タイトルは, 本文の上に貼り付く1行のタイトル欄 (アイコンとタイトル) です. スクロールしても常に見え, その場で編集できます. 長いタイトルはカーソルがない間は1行で省略し, カーソルがある間は全文を折り返します. スマホも同じです.
- 0.11.3ではエディタの上に段 (集中表示・開いているメモの名前・「タブ」・最近のメモ) を置き, 本文の大見出しと名前が重なっていました. Glesさんの提案 (段のタイトルを常に見せる案はよいが, 既存のタイトル欄は不要なので削除し, 常に見えるタイトル欄で編集したい, スマホにも) を受け, タイトル専用のエディタを置く案は, 元に戻す・色・メモ内検索が2か所に分かれてごちゃつくため (Glesさんも同じ懸念), 1つのエディタのまま大見出しを貼り付くタイトル欄に作り変える案を選んでいただきました (2026-10-26). 段は廃止し, その操作はツールバーの行へ移しました.
- 「タブ」を押すと, スマホと同じ開いているメモの一覧 (`OpenTabsPopover`) が, 角の丸いカードとして後ろを暗くして開きます. 押すとそのメモを開き, ×で閉じます. 外を押すと一覧を閉じます.
- 0.11.0では開いているメモを横に並べたタブの帯 (開く・閉じる・中クリック・ドラッグで並べ替え・横スクロール) でしたが, Glesさんの指摘 (帯がださい, スマホのようにタブ一覧を開く方がいい) を受け, Options Firstで3案 (タブボタン+浮く一覧・左端にスマホのナビを縦に・下部ナビをPCにも) を示して, 2026-10-26に「タブボタン+浮く一覧」に変えました. タブの並べ替えは, スマホと同じく行いません.
- 完了したメモは, エディタのタイトル・段のメモの名前・一覧の名前に取り消し線を付けます.

### 3. Writing Modeを集中表示に

- Writing Mode (縦のタブ一覧とエディタだけの画面) は, 「集中表示」に置き換えます. 集中表示では, トレイとメモの列 (タブレットではメモの列とトレイの引き出し) を畳み, エディタを画面の幅いっぱいに広げます. エディタの上の段はそのまま使えます.
- エディタの上の段の左端の同じボタンで戻ります. メモを削除したときなど, 一覧に戻る操作では集中表示を終えます (従来のWriting Modeと同じ).
- 縦のタブ一覧 (`vertical-note-tabs.tsx`) とその絞り込みは使わなくなるため削除します. 多数のタブからは, 段の「タブ」の一覧で選びます.

## 対象外

- スマホ (幅768px未満) の画面構成, エディタのツールバーとメモの操作, 一覧の中身は変えません.
- 列の幅のドラッグ (トレイとメモの境界) は従来どおりです.
- 集中表示の状態は保存しません (再読み込みで3列に戻ります).

## 確認

- PC (1440px・1280px) とタブレット (1024px) で, 共通ヘッダーがなく, 段の操作 (検索・言語・設定・アカウント) が使えること, 段の「タブ」の一覧で開く・閉じる, 最近開いたメモが使えること, 集中表示で一覧が畳まれ段が残ること, 横にはみ出さないことを確かめます.
- スマホ (390px) の画面が変わらないことを確かめます.
