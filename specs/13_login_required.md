# ログイン必須と認証喪失時の復旧

更新日: 2026-09-30. 0.5.0として実装・検証し, 本番公開済みです.

## 採用仕様

- Googleログイン後にのみ編集画面を表示します. 未ログイン時の編集可能なPreviewは撤廃します. Landing-pageはログインなしで閲覧できます.
- 初回ログインで保存済みWorkspaceがない場合は, 既存の初期サンプルから構築・保存します. Google認証方式・Firestoreルール・保存Schemaは変更しません.
- 認証喪失やアカウント変更の前に, 未保存の最新内容と最後の保存確認済み版を元のUID専用にページ内のメモリーへ保留します. 未ログイン画面には内容を表示せず, 別アカウントの初期状態や保存対象にも渡しません.
- 同じUIDで再ログイン後, サーバーの最新内容を読み込み, 既存の三方向統合・競合コピー・構造競合の確認処理を使って復旧します. 内容の読み込みに失敗しても保留データは残します. 復旧内容は保存成功後に「保存済み」とします.
- 別アカウントへログインしても元UIDの保留データを残し, 元のアカウントで戻るよう案内します. すべての保留データが復旧するまで, ページ離脱時の警告対象にします.
- 再読み込みやブラウザー終了後の保留データ復元は保証しません. 未保存編集の永続保管は今回の範囲外です. OSによる強制終了等では離脱警告も保証できません.

## 検証結果

- 保存キュー12件, 統合12件, ログインRetry2件, 認証喪失後の復旧5件, 公開番号・11言語案内3件の計34テストが成功しました. 対象Lintと型チェックも成功しました.
- 復旧テストでは, 同じUIDでの復帰, 別UIDへの分離, サーバー読込失敗後の保持, サーバー側設定との統合, 同時変更時の確認待ちを検証しました.
- localhost:9002の模擬DBで「ログイン画面 → 認証 → Memo編集 → DB通信遮断 → 同じブラウザーの別タブでログアウト → 編集を非表示にして保留 → 同じアカウントで再ログイン → 復旧・保存 → 再読み込み後も本文を保持」を確認しました. 1440pxと375pxで画面を確認し, ページの実行時エラーは検出されませんでした.
- ブラウザー検証は既存のPlaywright環境を使い, 一時スクリプトと画像はRepository外へ置きました. Browser plugin not available（Browserスキルが一覧にないため）です. 新しい依存関係は導入していません.
- 本番の個人データを使った認証失効・復旧テストは未実施です. 実際のトークン期限切れではなく, 認証状態の喪失を別タブのログアウトで再現しました.

## 公開

### 0.5.1のログイン案内修正 (2026-09-30, 本番未反映)

ログイン状態表示の重複を除き, ボタンだけにしました. ポップアップを自分で閉じた場合はエラー表示を出しません. ブロック時はブラウザーで許可して再試行する案内, その他の認証失敗はログイン再試行の案内を11言語で表示します. 内部コードは診断状態に保持し, ログイン画面には直接表示しません. サーバー読込失敗とは区別します. Landing-pageへの追加リンクは設けず, Brandリンクは維持します. 認証・復旧の10テストと公開情報3テスト, 対象Lintが成功しました.

localhost:9002の1440px・375pxで「表示は1つ → window.openを模擬的にブロック → 操作案内を表示 → 次の実ポップアップを閉じる → 案内を消して再試行可能」を確認しました. ページの実行時エラー・横スクロール・内部コード表示はありませんでした. その他の認証失敗はComponentテストで検証し, 本番データでの失敗再現は行っていません.

### 0.5.0の公開結果

0.5.0の番号・11言語の更新履歴・Landing-pageの利用条件を揃え, 本番接続Buildが成功しました. ユーザーの2026-09-30のログイン必須化指示と通常更新の継続許可により, `firebase deploy --only hosting --project drafta-memo --non-interactive`で公開しました. Firebaseプロバイダー・アクセスルール・課金プランは変更していません.
