## プラン設計

| 項目 | Free | Pro ($3/月) |
|------|------|-------------|
| ストレージ | 200MB | 10GB |
| 広告 | あり | なし |
| デスクトップアプリ | ❌ | ✅ |
| 追加ストレージ | ❌ | +10GB/$2（月額） |

### 通貨設定
- 基準: $3 USD/月
- 他通貨: Stripeによる自動換算

### 追加ストレージ課金ルール
- 方式: **積み増し型（累積）**
- 単位: +10GB / $2（月額）
- 反映タイミング: 決済成功後に即時反映
- 解約時: 次回更新日で失効（当月分は利用可）

## 同期設計

### 基本方針
- **クラウドオンリー**（オフライン非対応）
- インターネット接続必須

### デバウンス
- **条件付きハイブリッド**
- 入力中: **0.8秒デバウンス**
- 即時保存トリガー: `blur` / ノート切り替え / 手動保存（Ctrl+S） / `visibilitychange`
- 構造変更（画像追加・見出し変更・削除系）: 即時保存
- 楽観的UI更新（ローカルは即時反映、バックグラウンドで保存）

### リアルタイム同期
- Firestoreリアルタイムリスナー使用
- 変更されたドキュメントのみ受信（自動差分同期）

### 保存状態UI
- 表示状態: `保存中` / `保存済み` / `保存失敗`
- 保存失敗時: 自動リトライ（最大3回）
- リトライ失敗後: 手動再保存導線を表示

## データ設計（Firestore）

### ユーザー
```
/users/{userId}
  - email: string
  - plan: "free" | "pro"
  - storageUsed: number (bytes)
  - storageLimit: number (bytes)
  - createdAt: timestamp
  - updatedAt: timestamp
```

### メモ
```
/users/{userId}/notes/{noteId}
  - title: string
  - content: string (TipTap JSON)
  - createdAt: timestamp
  - updatedAt: timestamp
```

### 画像
```
/users/{userId}/notes/{noteId}/images/{imageId}
  - url: string (Firebase Storage URL)
  - size: number (bytes)
  - createdAt: timestamp
```

## ストレージ制限

### 制限到達時の挙動
1. 新規画像アップロード不可
2. 新規ノート作成不可
3. 既存メモの編集は可能（テキストのみ）
4. ノート削除は可能（容量回復のため）
5. アップグレード促進UI表示
6. 保護ノート（`note-1`, `note-2`）は常に編集不可

### ストレージ計算
- テキスト: contentフィールドのバイト数
- 画像: Firebase Storageの実サイズ

## 運用監視

### Firestoreリージョン方針
- 本番リージョン: **`us-central1`**
- 理由: 初期フェーズでは採算性と運用シンプルさを優先

### 監視指標（リージョン再評価トリガー）
- 月間アクティブ有料ユーザー数（Pro + 追加ストレージ課金）
- 保存失敗率（`保存失敗` / 全保存試行）
- 同期遅延のP95
- Firestore/Storageの月額コスト
- 障害影響時間（リージョン障害時）
