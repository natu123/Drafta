# Drafta 技術スタック

## プラットフォーム

| プラットフォーム | 技術 | 備考 |
|-----------------|------|------|
| Web | React + TipTap | 既存 |
| iOS / Android | Expo + TenTap | Mac不要（EAS Build） |
| Desktop | Tauri + TipTap | Pro限定 |

## バックエンド

| 項目 | 技術 |
|------|------|
| DB | Firebase Firestore |
| Storage | Firebase Storage（画像のみ） |
| Auth | Firebase Authentication |
| Hosting | Firebase Hosting |
